# vividDeck 使用说明

## 一、素材导入

- **导入图片**：工具栏「导入图片」，可多选 JPG / PNG / WebP / HEIC 文件
- **导入文件夹**：工具栏「导入文件夹」，递归导入文件夹内全部支持格式
- **拖拽导入**：把图片或文件夹直接拖到窗口任意位置
- 内容相同的图片（按文件内容哈希判断）会自动跳过，不会重复入库
- 导入方式在「设置 → 导入方式」中切换：
  - **复制到媒体库**（默认）：复制一份到应用数据目录，安全但占用双倍空间
  - **仅引用原文件**：不复制；但移动/删除原文件后图片失效

## 二、分类 / 标签 / 收藏

- 内置「风景 / 人物 / 动漫 / 极简 / 工作背景」预置分类，可在侧栏分类区点击 ✏️ 新增、重命名、删除（删除分类不会删除图片，图片回到"未分类"）
- **拖拽归类**：按住画廊中的图片卡片，拖到左侧栏目标分类上松手
- **标签**：双击图片打开灯箱 → 右侧信息面板添加/移除标签；侧栏标签云点击筛选
- **收藏**：卡片或灯箱中点击 ♥

## 三、筛选与检索

工具栏提供：文件名关键词搜索、分辨率（≥1080P / 2K / 4K）、文件大小（<1MB ~ >20MB）、排序方式；配合侧栏的分类 / 收藏 / 标签可叠加过滤。

## 四、设置壁纸（含多显示器）

1. 卡片双击、卡片左上角 🖥 或灯箱中点「设为壁纸」
2. 选择目标显示器（可多选，为不同显示器分别设置时逐台操作即可）
3. 选择填充模式：
   | 模式 | 效果 |
   |---|---|
   | 铺满 | 等比缩放覆盖全屏，超出部分裁掉（推荐） |
   | 拉伸 | 强制拉伸到屏幕尺寸，可能变形 |
   | 居中 | 原尺寸居中显示 |
   | 适应屏幕 | 完整显示整图，不足处留黑边 |
4. 应用会自动按每台显示器的**物理分辨率**预渲染后再设置，多屏不同分辨率各自吻合

**默认填充模式**：对话框中的「将此模式保存为默认填充模式」勾选框默认勾选——设置一次后，以后打开对话框会自动选用该模式，不必每次重选；也可以随时在「设置 → 默认填充模式」中修改。

## 五、轮播壁纸

侧栏「轮播计划」：

1. 打开「自动轮播」开关
2. 设置周期：每 N **分钟 / 小时 / 天** 切换
3. 选择素材范围：全部图库 / 收藏 / 指定分类
4. 选择顺序：**随机**（洗牌播放，不连续重复）或 **顺序循环**
5. 选择目标显示器（不选 = 全部）
6. 可随时点「立即切换下一张」

**重要行为**：
- 关闭主窗口后应用驻留**系统托盘**，轮播不中断；托盘图标右键菜单可「下一张壁纸 / 打开主界面 / 退出」
- 轮播进度本地保存，重启应用后按剩余时间继续，不会立即重播
- macOS 托盘左键单击可直接打开主界面

## 六、壁纸历史

侧栏「壁纸历史」：按时间倒序记录最近 500 次设置（含轮播切换），点击「重设」一键回溯复用。

## 七、裁剪工具

灯箱 → 点 ✂ 裁剪：自由比例 / 16:9 / 4:3 / 1:1 / 显示器原生比例；滚轮与滑杆调整取景，可「保存到素材库」或「保存并设为壁纸」。裁剪在**原图**上执行，画质无损。

## 八、主题与设置

设置 → 外观：跟随系统 / 亮色 / 暗色。

**默认填充模式**：设置壁纸时默认使用的填充模式，避免每次手动选择（设壁纸对话框中的勾选框也会自动保存）。

**数据存储位置**：全部素材、缓存与配置默认保存在 `用户数据目录/vividDeck/storage/`；点击「更改存储位置…」可整体迁移到大容量磁盘或外置硬盘：

- 迁移采用**先复制后切换**：中途断电/取消不会丢失任何数据，确认成功后才切换并自动重启应用
- 素材库较大时（如数 GB）复制可能需要几分钟，期间界面会显示"正在迁移"
- 选中的目录若非空，会自动在其中创建 `vividDeck` 子目录
- 使用外置磁盘时注意：未挂载时启动应用会弹窗提示（不会清空数据），挂载后重试即可
- 迁移成功后，旧目录可手动删除以释放空间

> 说明：数据以 JSON 文件形式保存（非 SQLite 数据库），同样支持更换目录、可直接查看与备份。

## 系统权限说明

### macOS（Ventura / Sonoma+）

- **设置桌面壁纸不需要任何特殊权限**，不会触发"自动化/屏幕录制"等隐私授权弹窗
- 如果导入的图片位于「桌面 / 文稿 / 下载」等受 TCC 保护的文件夹，首次读取时系统可能弹出"访问文件夹"确认框，点击「允许」即可（这是 macOS 对所有第三方应用的标准流程）
- 首次运行未签名/未公证的开发版应用：右键点击应用 →「打开」→ 再点「打开」（正式发布建议配置开发者签名与公证）

### Windows（10 / 11）

- 设置壁纸调用系统 `IDesktopWallpaper` 接口，**无需管理员权限**
- 若安全软件拦截 PowerShell 脚本（用于调用系统壁纸接口），允许运行即可；脚本位于应用数据目录 `bin/wallpaper.ps1`，内容开源可审查
- 高 DPI 缩放（125% / 150% 等）已自动适配：按显示器物理分辨率预渲染

## 常见问题

**Q：轮播没有按时切换？**
A：确认应用未真正退出（检查系统托盘是否有 vividDeck 图标）；确认轮播开关已打开且素材范围内有图片。

**Q：Windows 上设置壁纸失败？**
A：先确认普通方式（系统设置→个性化）能正常更换壁纸；若使用了动态壁纸类软件（如 Lively、Wallpaper Engine），它们可能接管桌面，请退出后再试。

**Q：HEIC 图片（iPhone 拍摄）能导入吗？**
A：可以，应用内置解码，不依赖系统编解码器；缩略图与预览会自动转码生成。

**Q：删除图片会删掉我的原文件吗？**
A：复制模式导入的文件只是移入系统废纸篓（可恢复）；「仅引用」模式删除时**不会**动原文件，只移除记录。

## 数据隐私

分类、收藏、标签、轮播配置、壁纸历史全部保存在本地（可在 设置 → 打开本地数据目录 查看），**不上传任何云端**。（二期将提供可选的 MinIO 自建存储同步）
